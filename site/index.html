# 产品愿景与原则

Unlimited Wiki 为团队提供一个本地优先、默认私有、可控分享的知识平台。

## 核心原则
  • 本地优先，数据可控
  • 默认私有，最小公开
  • Markdown 优先，开放可携带
原始资料 product-notes.pdf research.md
发布流程
  1. 1草稿
  2. 2AI 预审
  3. 3人工审核
  4. 4公开发布

从原料到知识正本

一条可追溯、可恢复、可持续治理的知识工作流。

01

收集 Raw

原料进入私有收件箱，保留来源标识。

product-notes.pdfPDF
research.mdMD
architecture.pngOCR
02

沉淀 Markdown

整理为可编辑、可链接、可迁移的正本。

# Product principles ## Context - Local-first - Private by default
03

协作治理

权限、健康检查、版本与任务保持可见。

权限Owner · Editor · Viewer
健康检查PASS
版本历史v3 · v2 · v1
04

预审与人工审核

不可变快照依次经过 AI 预审和人工审核。

1AI 预审
2人工审核
05

Wiki 广场

发布不可变公开版本，保留来源、版本历史与纠错入口。

Public revision v3 · published 来源 · 历史 · 纠错

失败可见，任务可重试，审核流程不会静默改写私有正本。

快速开始

git clone https://github.com/nssntus/unlimited-wiki.git
cd unlimited-wiki

python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt

npm --prefix viewer ci
npm --prefix viewer run build

python3 serve.py

默认访问 http://127.0.0.1:8765
